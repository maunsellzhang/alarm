# 轻提醒（alarm）

适配 Windows 11 的桌面闹钟应用，支持指定日期和时间提醒，也可以设定倒计时。提醒到期时显示置顶窗口并播放声音，可直接稍后提醒或重新设定时间。

使用 C#、WPF 和 .NET Framework 4.8 开发，提醒记录保存在本机，应用运行不依赖账户或云服务。

## 功能一览

- **两种提醒方式**：指定日期时间，或按小时、分钟、秒设置倒计时。
- **快捷倒计时**：5、15、30、48 分钟和 1 小时，支持手动输入及分钟、秒自动进位。
- **记住每条提醒的间隔**：到期后可以按原时长再次提醒，也可以修改下一次的间隔。
- **托盘运行**：关闭主窗口后继续提醒，重复启动会唤起已有窗口。
- **到期补提醒**：电脑唤醒或应用重新启动后，补发已到期但尚未完成的提醒。
- **本地数据保护**：原子保存、上一版备份、损坏数据保留及恢复日志。

开发者可阅读 [开发与验证说明](docs/DEVELOPMENT.md)，了解代码职责、构建流程和测试入口。

## 构建与运行

### 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 11 |
| 运行时 | .NET Framework 4.8 或更高的兼容 4.x 版本 |
| 构建工具 | Windows PowerShell 和系统自带的 .NET Framework C# 编译器 |
| 第三方依赖 | 无需下载第三方包，也不需要安装 Visual Studio 或 .NET SDK |

### 获取源码

```powershell
git clone https://github.com/maunsellzhang/alarm.git
cd alarm
```

也可以在 GitHub 仓库页面选择 **Code → Download ZIP**，解压后在项目目录打开 PowerShell。

### 编译并启动

在项目目录执行：

```powershell
.\build.ps1 -Test
.\dist\QingReminder.exe
```

若 PowerShell 的执行策略阻止本地脚本，可在当前命令中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

构建结果为 `dist\QingReminder.exe`，也可直接双击运行。程序使用普通用户权限，构建脚本会生成应用图标，并将界面资源嵌入可执行文件。

如果旧版仍在托盘运行，可用 `.\build.ps1 -OutputDirectory .\dist\updated` 将新版构建到独立目录。退出旧版后打开 `dist\updated\QingReminder.exe`，会自动读取已有的提醒记录。

## 使用方式

1. 在主窗口选择「指定时间」或「倒计时」，填写标题和时间后添加提醒。倒计时最长支持 365 天。
   默认打开倒计时页面，提供 5、15、30、48 分钟和 1 小时的快捷选项；选中时长会以绿色突出显示。
   分钟和秒可输入超过 59 的非负整数，添加或保存提醒后自动进位，例如 70 分钟换算为 1 小时 10 分钟，70 秒换算为 1 分钟 10 秒；总时长仍需在 365 天以内。
2. 已设定的提醒显示在列表中，可编辑时间、标题或删除。
3. 提醒到期后，弹窗直接提供小时、分钟、秒输入框，可手动设定下次提醒的间隔，点击「再次提醒」（指定时间闹铃显示「延后提醒」）保存并开始新的倒计时。「更多设置」可打开主窗口编辑日期、时间或提醒内容，也可以直接「完成」。
4. 关闭主窗口后，程序保留在系统托盘。通过托盘打开主窗口；通过应用菜单退出程序。

关闭提醒弹窗或按 Escape 会自动延后 5 分钟。取消重新设定会重新显示尚未处理的提醒。

倒计时闹铃会记住各自的时长。设定 48 分钟后，到期弹窗默认回填 `00:48:00`，不修改直接点击「再次提醒」即可从当前时刻重新计时 48 分钟。弹窗内手动修改时、分、秒并保存后，会记住新时长，下一次提醒和重启后继续回填新值；分钟和秒超过 59 时自动进位。关闭弹窗或按 Escape 临时延后 5 分钟，不会覆盖记住的时长。「更多设置」中的重新设定也会回填已保存的倒计时时长和提醒内容。

旧版记录没有单独保存倒计时时长，新版会从到期时间和创建时间恢复可用的时长。若记录在旧版中已经反复修改或延后，无法保证还原最初的间隔；重新设置并保存一次即可明确后续的默认时长。

程序需要保持运行才能准时提醒。电脑关机时无法提醒；休眠或睡眠期间到期的提醒会在唤醒后补发。退出应用后重新打开，也会补发已到期、尚未完成的提醒。倒计时以保存的实际到期时间计算，睡眠期间仍然计时。

## 数据与验证

提醒数据保存在 `%LOCALAPPDATA%\QingReminder\reminders.json`。写入采用原子替换，上一份有效数据保存在同目录的 `.bak` 文件。若数据损坏，原文件会保留为带时间戳的 `.corrupt.*.json` 文件，并记录恢复日志。

`build.ps1 -Test` 会运行核心测试，验证指定时间与倒计时、重复轮询、重启补提醒、稍后提醒、重新设定、输入验证、损坏数据备份，以及写入失败后的状态一致性。

运行 `.\verify-ui.ps1` 可验证实际 WPF 界面的创建、提醒、延后和重新设定流程，并在 `.artifacts\ui-tests` 生成界面截图。构建前应退出已运行的应用，以免可执行文件被占用。

应用基于 WPF 和系统托盘实现，使用 Windows 11 兼容声明及高 DPI 感知清单。

## 后台占用与资源验证

主窗口显示时每秒刷新时钟和剩余时间，隐藏或最小化后停止界面刷新。后台根据最近一条闹铃安排检查，最长间隔 60 秒；没有待触发闹铃时停止计时器。系统时间变更或电脑唤醒时会立即重新检查到期提醒。重复启动通过系统事件唤起已有窗口，无持续轮询。

空轮询不再复制全部闹铃，界面只在记录变更时读取新的列表快照。固定画刷会缓存并冻结；静音提醒停止声音计时器，关闭提醒及退出应用时解绑计时器、系统事件，并释放托盘菜单和图标。

提醒状态保存失败时保留原计划、显示错误并间隔 15 秒重试，避免持续写盘。弹窗创建或显示失败时会清理部分窗口，保留全部待显示提醒并间隔 15 秒重试；其中一条失败不会中断其他到期提醒，退出或重新设定时也会清理旧的待显示项。损坏数据恢复日志达到 256 KiB 后轮换保留上一份，损坏数据备份继续保留。

运行 `.\verify-resources.ps1` 可在隔离数据目录验证隐藏提醒、睡眠恢复通知、写入失败重试、单例事件和资源释放，并测量可见及隐藏状态各 30 秒的 CPU、内存和句柄占用。结果写入 `.artifacts\resource-tests\resource-report.txt`。压力测试中的强制垃圾回收仅用于确认已关闭对象能被回收，应用本身不主动强制垃圾回收或清空工作集。短时测量不能替代长期运行观察，WPF 的字体和渲染缓存也会占用内存。
